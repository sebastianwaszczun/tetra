01 / Najważniejsze ograniczenia

Cztery rzeczy, o których trzeba wiedzieć

0kluczy API potrzebnych do sprawdzenia działania
1model z ograniczeniem komercyjnym (InsightFace)
CPUwszystkie modele działają bez GPU
0 Bdanych organizatora w repozytorium
  1. Modele twarzy InsightFace (buffalo_l) są dostępne tylko do niekomercyjnych badań. Kod InsightFace jest na licencji MIT, ale wytrenowane modele – nie. Do użytku komercyjnego trzeba kupić licencję albo przełączyć analizę twarzy na sam YuNet + SFace (MIT, Apache 2.0), które system już obsługuje: w config/obraz.toml w sekcji [twarze] zmienić tryb = "oba" na tryb = "jeden" i dopisać model = "yunet_sface". Progi SFace są już skalibrowane w tym samym pliku ([twarze.yunet_sface]).
  2. Dane organizatora (paczka NASK) nie są rozpowszechniane – nie ma ich w repozytorium (.gitignore).
  3. Zdjęcia w bazie referencyjnej osób mają różne licencje (opisane w zrodla.json każdej osoby); część ma status „nieustalona – użycie wyłącznie lokalne” i nie jest publikowana (folder data/).
  4. Meta Ad Library API wymaga własnego tokenu i akceptacji warunków Meta; tokenu nie ma w repozytorium.
