# front – landing (kot detektyw)

Jednostronicowy hero w React + Vite.

```bash
cd front
npm install
npm run dev      # http://localhost:5173
npm run build    # -> dist/
```

- `src/App.jsx` – cała strona i logika animacji kota (fazy: idle → jump → pull → open → closing)
- `src/index.css` – style 1:1 z projektu
- `src/assets/cat/` – klatki kota (sit-0…5 siedzi/pisze/patrzy, jump, hang)
- `src/assets/fonts/` – Gloria Hallelujah + Patrick Hand (OFL)
